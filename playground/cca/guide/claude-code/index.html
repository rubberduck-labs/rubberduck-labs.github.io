Claude Code20% of the exam

Remember

  • CLAUDE.md levels: ~/.claude/CLAUDE.md is only yours; the project one is committed; subfolders load when you work there.
  • Keep it modular with @path/to/file imports. /memory shows what's loaded.
  • Rules for file types go in .claude/rules/ with paths: ["**/*.test.tsx"]. They load only for matching files.
  • Skills load on demand; CLAUDE.md always loads. Team ones in .claude/, personal ones in ~/.claude/.
  • Skill frontmatter: context: fork isolates output, disallowed-tools removes tools, allowed-tools pre-approves them.
  • Plan mode for big, multi-file or architectural changes. Direct execution for small, clear fixes.
  • Unfamiliar domain? Interview first. Unclear transformation? Give 2–3 input/output examples. Tests first.
  • CI: -p plus --output-format json --json-schema. Review with a separate instance and pass earlier findings.

Don't mix up

~/.claude/CLAUDE.md: you only.Project CLAUDE.md: the whole team.
.claude/rules/ with paths: by file type, anywhere.Subfolder CLAUDE.md: one folder.
allowed-tools: runs without asking.disallowed-tools: can't run at all.
/clear: new, unrelated task./compact: same task, less context.
Plan mode: several ways to do it.Direct execution: one obvious fix.
