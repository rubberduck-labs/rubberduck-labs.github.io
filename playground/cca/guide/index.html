The exam in four lines

  • 60 questions, 120 minutes. Some ask for one answer, some for several.
  • 4 scenarios out of 6: support agent, Claude Code for a team, multi-agent research, developer tools, Claude Code in CI, data extraction.
  • Pass at a scaled 720 of 1,000.
  • Unofficial site: practise here, but check the official guide.

Where the exam guide and today's models differ

  • The guide teaches tool_choice any and forced tools. Claude Opus 5.5 and Sonnet 5.5 reject both; use auto with clear instructions, or structured outputs.
  • The guide says Task; current SDKs call the subagent tool Agent.
  • The guide treats a skill's allowed-tools as a restriction. Today it pre-approves tools; disallowed-tools removes them.
  • Assistant prefill is rejected on current models; use structured outputs.
